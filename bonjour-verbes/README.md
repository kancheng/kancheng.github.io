# Bonjour Verbes

A beginner-friendly French conjugation guide for être, avoir, and s’appeler, with Chinese translations, example sentences, audio playback, and a downloadable PDF.

法文 A1 學習小抄：三個常見動詞的現在式、六組人稱、18 句例句和繁體中文翻譯。

## 使用

直接開啟 `dist/index.html`，按例句旁的播放鍵跟讀；按「下載完整 PDF」取得列印版。發音使用瀏覽器 Web Speech API，法語語音取決於裝置的語音套件。

## 專案結構

- `dist/index.html`：單頁網站
- `dist/Bonjour-Verbes-A1.pdf`：可下載的小抄
- `generate_pdf.py`：產生 PDF 的程式
